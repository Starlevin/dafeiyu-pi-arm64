# 大肥鱼｜长期记忆隔离、回复去重、分场景回复（P1）

2026-11-09 · 功能分支 `feat/pi-memory-context-dedup-20261109`

## 当前线上基础

已核对生产 Pi 的 `config.memoryEnabled=true`；4 个授权会话有保存的长期记忆，整理器已成功完成最近批次，现有存储按 QQ 会话隔离。旧系统没有必要重建记忆库或上传聊天。生产原始配置始终优先，禁止导出 QQ 消息正文、凭据和账号信息。

## 本次功能

1. **长期记忆安全与去重**：沿用持久化 `QQMemoryBook`、增量整理、历史纠错与遗忘接口。修复 `QQMemoryIndex.search` 可能混入同一群其他成员事实的问题：检索与评分只接受本轮真实说话人的 `subject`，不能把另一成员的偏好当成对方的事实。整理输出对同一主体同类型的仅标点/空白差异进行精确规范化去重，但保留“喜欢”与“不喜欢”等相反事实，并保留纠错／遗忘机制。
2. **重复回复**：在每次生成前，仅取当前 QQ 会话最近的已确认 BOT 发送内容（单会话作用域，兼容旧持久化记忆和短期历史）作为低信任对话资料，要求模型不要机械复读；最终准备发送时检查较长的同文/标点改写。如果没有明确要求“重复/再说一遍”，且不是图像/工具结果、不是兜底短句，则跳过完全重复的实质性回复。绝不跨好友/群混用、绝不自动额外发消息，也不因“你好”“好的”等简短应答反复出现而静默。
3. **分场景回复长度**：低成本确定性规则识别简短问候、普通聊天、复杂提问。以面板 `persona.maxCharacters` 作为最高授权上限（项目允许 20–200）；三种场景上限分别为 50 / 120 / 160 字，群内主动发言若已由用户授权也仍最多 50 字。遇到认真求助，允许表达依据与步骤；问候不灌水。单轮 `fast` 路径不再附加“只能短答”的硬指令，但仍维持 JSON 输出、身份/白名单/工具/额度限制。
4. **主动插话不在本轮范围**：不变更 `groupParticipationEnabled`、`groupParticipationEvery`、任何随机概率或现有目标列表。生产检查时其当前值为 `false`；增加概率机制必须先获得用户独立审核。

## 配置与验收边界

代码本身不会无授权提升用户保存的 `maxCharacters`。当前生产仍为 **60 字**，必须在新二进制构建和脱敏回归测试通过后，再通过原授权面板把它调整到建议的 160 字，这样场景差异才能完整生效。暂不修改 `ai.maxTokens=500`；可根据真实响应质量后续独立调整。保留 `fast + high`、既有回复白名单和模型接口。

必需测试：跨群成员/私聊记忆隔离、同语义标点重复、明确纠正、不误伤简短问候、各场景预算、保留用户硬上限、重复回复不增加发送范围，以及原有 `QQMemoryBookTests` 与 `QQPersonaTests`。真实 QQ 消息与实际模型调用需独立维护窗口才测；没有部署不宣称线上已生效。

## 可预见副作用与回滚

- 长期记忆整理依旧按旧阈值和额度调用模型；本改动不新增自动巡查，不启用新的额外 QQ 发送。
- 只有实质性的文本原句重复才可能被跳过；如发现用户问新问题却被误判，回滚去重守卫而保留记忆隔离。
- 如新版本崩溃、QQ 连接不稳定或控制端口失效，恢复上一个经验证的本地二进制与原配置；不触碰 QQ 登录态。
