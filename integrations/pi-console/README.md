# 大肥鱼 Pi 统一控制台

这是大肥鱼树莓派统一控制台的公开源码快照，包含 Python 服务、静态网页界面、用量记账模块、合成夹具和源代码级测试。

## 范围与许可

- 本目录原创的服务端、网页、适配器、用量记账代码及测试，适用仓库根目录 MIT License。
- `server/qrcodegen.py` 来自 Project Nayuki 的 QR Code generator Python 实现；文件保留上游完整 MIT 许可声明。来源与第三方许可见 [`THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md) 和[上游项目页](https://www.nayuki.io/page/qr-code-generator-library)。
- `server/fixtures/` 是合成数据，不代表真实 QQ、微信、NapCat、账号、群组或运行状态。
- 此目录不包含 NapCat、微信客户端、模型网关或其他后台的源代码/二进制。`model-hub-usage/usage_ledger.py` 是本项目的用量记账集成；对已安装模型网关的补丁脚本和第三方实现没有复制。

## 使用前说明

- 默认 HTTP 入口只绑定 `127.0.0.1`，来源网段默认仅限回环地址。局域网入口关闭；启用时必须由部署者单独配置监听地址、证书和允许网段，并自行检查防火墙。
- 服务不会猜测 QQ、NapCat 或微信数据目录。部署者须用本机私有配置或环境变量显式提供路径（如 `DAFEIYU_QQ_ROOT`、`DAFEIYU_NAPCAT_ROOT`、`DAFEIYU_CONSOLE_STATE_HOME`）；管理密钥不得提交到 Git。状态文件默认写入用户私有状态目录，仓库已忽略运行状态与本机配置。
- 页面包含管理员操作。显式配置后台后，按钮可更改回复范围、模型设置或 NapCat 配置，也可请求重启 QQ；运行前应先审阅目标实例与变更。此公开快照没有发布者生产实例的地址或凭据；部署在用户设备后，页面操作会访问用户自行配置的本机后台。
- 网页内容阅读仅针对公开内容；默认不启用平台搜索。用户启用后，模块会发起真实网页读取并调用其自行配置的模型网关。须遵守平台条款、隐私规则和当地法律。
- 公开整理过程中未连接树莓派、未读取生产服务、未发送真实消息、未执行部署或后台维护操作。功能验收状态为 **NOT_RUN**。
